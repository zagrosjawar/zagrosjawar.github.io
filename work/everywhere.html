EVerywhere

Helping EV drivers find a charger, not a headache.

TEAM5 students
MY ROLEUX/UI & development
CONTEXTCourse project (MIX114), University of Bergen
TIMELINESpring 2024
The problem

EV drivers need to know where to charge — and whether a station will actually be free when they get there. EVerywhere maps charging stations across Norway, plans routes around them, and shows usage data so drivers don't waste a trip on a full charger.

Process

A full design sprint — "How Might We" questions, 2-year goals, Crazy 8s, and a storyboard — landed on a mobile-first, minimalist design so drivers aren't distracted while driving. Built from Figma into a working app with Google Maps API, Highcharts, and a custom API for charging data.

A monochrome teal palette with few elements per screen kept the focus on the road, not the interface.

The key decision

No usage-data API existed for EV charging stations in Norway — so the team built one. A custom API on npoint.io powers the usage statistics shown for each station, giving drivers a sense of how busy a charger typically is, using realistic mock data.

Result

A working prototype covering the full flow: connecting a car, planning a route, driving with live directions, and browsing nearby stations with usage stats. Built with HTML, CSS, and JavaScript from a high-fidelity Figma design.
